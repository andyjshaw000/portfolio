Restaurant Finder

I like food and I like code, so I built a web app that pulls restaurant data from Yelp and puts it on an interactive map. Search for something, and you get every nearby spot color-coded by rating.

At a glance2 min read
Problem

I wanted a faster way to see which nearby restaurants are good.

What I did

My first Python project: Flask, Folium, and the Yelp API, paginated past its 50-result cap.

Result

A deployed web app with a color-coded restaurant map.

PlanningBuilding itDeploying it

Planning

This was my first time using Python. I planned three core features: search, ratings and reviews, and an interactive map. I chose Yelp Fusion for the data, Flask for the web app, Folium for the map, and the Google Maps API for a better map experience.

The must-haves were the map and getting it deployed. Colors, marker sizes, tooltips, and a moving map were next.

Building it

Getting enough data. Yelp only returns 50 restaurants per request. I made multiple requests with different offsets and saved the results to a CSV, so the map shows every restaurant nearby.

Search. Flask takes what you type and sends it to the Yelp API as a parameter.

The map. Markers are color-coded by rating so you can spot the good places fast. Click one and you get the rating, review count, and a review snippet. You can pan, zoom, and drag around the area.

Deploying it

Deploying to PythonAnywhere meant reworking my Flask routing to fit its setup.

Going in, I'd never written Python. Coming out, I'd used HTTP requests, parsed JSON, built a Flask app, and shipped it to the web.
